# 环境能力检查、补充建议与兜底

## 何时检查，检查到什么程度

第一轮明确论文目标后，在第二轮材料与可行性阶段选择需要的能力；第三轮定位同时给出能执行的方案、缺口与替代办法。进入具体步骤前，对尚未验证的目标做最小检查。只改一段正文时不体检数据库、浏览器或全机软件。用户在设计本技能时不启动其账户或应用中的实际论文任务。

先看当前会话暴露的工具及可用技能目录，再查看已知工作目录与配套运行环境。工具可动态发现时按能力检索，不能将未在简短目录中出现视为不存在；当前环境没有工具发现机制时如实说明检查范围。不要全盘扫描，不输出原始连接配置、密码、令牌或无关账户内容。

必要时读取工作区依赖定位工具返回的运行环境，不能把全局 Python/Node 的库当作配套环境也已安装，反之亦然。本机命令路径可见只说明发现了程序，不证明项目依赖、启动和测试可用。

已有专用工具与已连接服务优先于为同一任务另装一套。读取其文档或相关技能后再使用，不能猜造 MCP 名称或工具参数。Skill、MCP/插件、应用程序与运行库分别记：Skill 是指引；MCP/插件暴露能力；账户、目标权限、依赖和运行状态仍需核实。

初始化脚本也不是唯一入口。没有 Python 或本地执行工具，但有文件编辑工具时，按工作区指南和脚本中的模板手动补建本轮需要的文件，保持只补缺、不覆盖的规则；不为创建几份 Markdown 强制安装运行环境。完全没有文件写入能力时先在对话中整理访谈、定位及后续源稿，明确需要用户保存，不能声称已建立本地目录。

## 状态与记录

每项能力用以下状态之一，不用简单的“有/没有”代替验证：

| 状态 | 具体含义 |
| --- | --- |
| 未检查 | 尚未按本轮任务发现或探测 |
| 已发现待验证 | 工具/技能目录或命令路径可见，目标能力未试用 |
| 最小验证通过 | 本轮限定目标与动作已有成功结果；只覆盖记录的范围 |
| 部分可用 | 例如能读文本但不能读取图片、写回或渲染 |
| 缺失 | 在明确检查范围内未找到实现该能力的工具或运行条件 |
| 访问受限 | 工具存在但目标未授权、登录缺失或权限不足 |
| 执行失败 | 已尝试动作失败，保存脱敏错误与已试替代方式 |
| 不适用 | 本轮任务不需要该能力 |

复杂任务的 `intake/environment.md` 或已有同职能记录按下表更新，不只罗列软件名；单次文字任务可在回复中说明所用能力，不强制创建新记录：

```text
任务与路径：本轮要完成什么
检查时间与范围：当前会话、指定文件夹和必要目标
能力 | 必需/增强 | 已发现工具或技能 | 最小检查及证据 | 状态 | 支持范围 | 缺口 | 替代路径 | 用户待办
执行方案：优先路径、降级产物、仍可继续事项、不能完成事项
```

定位确认不等于全部能力已验证。会话切换、工具更新、目标变动或执行失败时仅复核有关项；不要每轮重新枚举全部软件。过程性工具诊断留在此记录，不搬成论文正文里的免责声明。

## 能力与替代路径

| 所需能力 | 优先与最小验证 | 补充或兜底 |
| --- | --- | --- |
| 文件和源码读写 | 当前文件/IDE/本地执行工具，读取用户指定的小文件；需要写入时用独立临时文件验证，不能试写正式稿 | 只读条件下完成取证；没有文件工具则在聊天交付可复制文本，并请用户保存或提供指定材料。不能声称已落盘 |
| 文档读取与编辑 | 文档连接先确认目标会话和支持的操作，读取指定段落；离线文件按格式使用已有文档技能及工具 | 外部文档不可访问时先查合适连接；仍不可用或用户不连接时，请其导出原件或文本到工作区。能提取文本不等于保留样式或可写回 |
| Word生成和页面检查 | 分别验证文件生成、样式/域支持、页面渲染与查看能力；必要时只用临时样例，不动正式稿试工具 | 已有本地生成库或应用可替代连接；无生成能力交 Markdown/章节源稿。能生成但不能渲染时标可编辑初稿、格式未验收，不假称版式通过 |
| PDF与扫描件 | 区分可提取文本、页面渲染及 OCR，验证指定页面；先用当前已有格式工具 | 缺 OCR 时请提供可搜索原件或转写；缺页面查看不能完成视觉验收。文本提取可能遗漏图表、批注和公式，必要内容回原页 |
| 联网与文献全文 | 原生搜索和页面读取优先，区分搜索结果、原文获取与付费/登录全文访问 | 特定文献服务缺连接时先查插件；不连接可用用户合法提供的原文/书目信息。仅有摘要不假称已读全文，无法核实的文献不补造 |
| 浏览器操作与截图 | 当前浏览器控制/自动化或应用控制工具；访问用户已授权的目标，验证必要页面和实际截图能力 | 无专用工具时按规则用已有本地自动化设施；都不可用则给具体操作步骤，由用户提供真实截图及操作记录，标为用户提供。网页搜索或打开标签页不能替代浏览器交互；不生成假界面 |
| 数据库与SQL | 根据任务选择读取 SQL 文件或连接只读元数据；只有本轮需要运行库事实时才对指定连接做最小探测 | 无连接可用 SQL/迁移与实体取证，或用户导出的结构/只读结果；前者只支持脚本定义。连接成功不等于迁移、数据或事务路径已核实 |
| 本地启动与测试 | 识别所需运行时、依赖、现有实例、测试账号、隔离数据与配置目标，再验证有关启动或测试步骤 | 缺运行条件先做静态取证和测试计划；用户也可在本地执行明确命令并提供原始日志，标明来源。未执行不记通过，缺可选外部服务不阻止其他路径 |
| 数据分析与图表 | 对真实样本验证可用分析工具/库及必要方法；输出要可回溯数据与处理步骤 | 使用已有合法分析报告或可核实的小规模计算；缺关键数据不生成结果。绘图工具不可用时可交付可编辑图源或图表说明，标记未渲染；不虚构图中的数值 |
| 学术表达审查 | 可用的 academic-humanizer 或其他适用技能，先读取其规则 | 没有相应技能时按内置表达指南审查，明确未调用外部技能；不把润色能力当作事实核实能力 |

需要访问文档会话时先列会话、选择用户目标、查支持的操作，再执行其最小读取；工具目录可见不等于存在有效文档会话。未授权或目标不明确时不遍历所有文档内容。数据库和浏览器同样只探测有关目标，不为体检随意登录或写业务数据。

## 缺少能力时怎么建议

先判断是缺工具、缺授权、缺目标材料，还是配置/执行失败，再提供对应建议。工具已安装但当前会话没有暴露接口时，可建议启用连接或按官方说明重新加载，不直接重复安装。建议必须服务当前缺口：

1. 已有可用工具或本地设施能完成就直接使用，不要求用户为原生检索等能力另装插件。
2. 需要特定外部服务且当前不能访问时，若插件管理或技能发现工具可用，先搜索确有的选项再推荐。用户手动提供材料的路径可同时准备，但不未经发现就断言没有连接。
3. 建议通常限 1—3 个必要项，给出实际发现的名称/ID、任务作用、缺口、必要或可选、验证过的官方入口/平台建议项，以及不安装时怎样继续。不根据记忆编造下载链接、价格、兼容性或安装命令；需要说明当前安装方式时核对官方资料。
4. 当前环境没有插件发现或联网时，如实标记“未能核实具体安装选项”，只说明所需能力类别和可用替代办法，不伪造已推荐或已安装的产品。
5. 安装、连接账户、下载运行依赖和修改系统配置按用户已有授权执行，不把论文写作授权自动扩大成环境改造；必要用户操作一次说清，避免重复确认。登录应由用户在正常授权界面完成，不索要密码或令牌。

缺材料时请求具体可用的原件、学校规范、真实数据或日志，并说明用途；不要只说“补充更多信息”。有异步提问工具时可用它询问文本信息或选择，但附件请求用普通对话提出。用户不安装时执行已可行的替代路径，不反复推销工具。

## 执行与停止条件

- **增强能力缺少：**继续可行替代方式，例如使用内置润色规则；记录实际工具和来源。
- **交付能力缺少：**先完成可读源稿或未验收初稿；说明与所要求正式 Word/截图等交付的差距，保留未完成项，不能当成已完全交付。
- **关键证据或必要访问缺少：**暂停依赖部分，继续有依据的背景、蓝图、材料任务及其他章节；不能用替代工具制造事实。
- **需要改变研究定位或正式交付：**展示具体影响与可选方案，取得用户选择；用户未回应不算接受改变。临时源稿可先做，但不能自行取消已请求的正式交付。
- **工具失败：**根据实际错误修复可逆的调用或尝试合理替代；同一原因复现且无新信息时停止重复调用，说明阻碍及用户最小待办。不要绕过权限或继续执行有破坏性副作用的探测。

可执行性取决于材料、工具与授权的交集。拥有完整工具不能替代真实研究；缺少某个插件也不意味着只能停止写作。
