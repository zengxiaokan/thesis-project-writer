# 文献检索、核实与综合

在本轮需要查找文献、撰写相关工作、核对引文或解释研究分歧时读取。已有可靠记录则接续本轮涉及部分，不要求重新检索全部文献。该流程用于通用证据组织；专业研究设计、统计推断和学科方法仍需相应规范与专业审查。

## 先确定问题和交付范围

先写出本节要回答的问题，以及它在论文中的作用。例如：说明可选方法、比较特定约束下的方案，或为某个设计选择提供依据。列出对象、任务、适用条件和拟引用的主张；不要先凑参考文献数量再拼接摘要。

按任务设置范围：本科相关工作通常采用透明、有限的检索与主题综合即可。只有学校或研究问题确实要求时，才设计系统综述所需的完整协议与筛选流程。未执行相应方法，不使用“系统综述”“全面覆盖”等名称。日期、平台、语言和访问条件是检索边界，不是整个领域的边界。

复用已有 Evidence 结构；需要时增加检索日志和阅读矩阵，不强制迁移旧稿。示例见 [小型文献综合实例](../examples/literature-synthesis/README.md)。

## 记录实际发生的检索

每轮记录以下内容，结果页不可访问时也保留失败与替代路径：

| 字段 | 应记录的内容 |
| --- | --- |
| 问题与范围 | 问题、对象、时间范围、语言、文献类型、平台选择理由 |
| 检索操作 | 日期、平台、精确检索式、过滤条件、排序方式；按已知 DOI 或标识符查找时注明“定向核验” |
| 结果与选择 | 实际查看的条目或结果范围、导出记录位置、纳入和排除理由、重复与版本关系 |
| 停止原因 | 已足以支撑当前章节、时间限制、访问受限或尚有关键空缺；不要把停止检索写成研究饱和 |
| 下一步 | 待核实书目、待获取原文、待阅读段落和仍需反方证据的问题 |

设计检索式时将研究对象、方法和目标问题拆成关键词组，补充中英文同义词；用少量已知相关论文检查能否召回。记录实际使用的式子，不把建议的检索式写成已执行。为关键结论补查不同方法、负面结果和研究限制，可沿原文参考文献追溯或查看后续引用；未执行的追溯只列待办。

按 DOI、稳定文献标识符及题名/作者合并重复记录。预印本与出版版关联到同一工作，记录版本差异和实际阅读版本；不要把版本重复算作独立研究。先按题名摘要筛选，再按与本节问题的关系决定精读范围；保留关键排除理由，不用“质量低”等无法复查的标签代替标准。

## 将四种状态分开

| 状态 | 可接受证据 | 不能自动推出的结论 |
| --- | --- | --- |
| 书目已核实 | 作者或出版方页面、正式会议/期刊记录、官方预印本页；比对题名、作者、年份、标识符与版本 | 已读原文、方法可靠、支持当前引论点 |
| 全文可访问 | 实际成功打开对应版本的全文，并记录地址与日期 | 已阅读全文；看到下载链接也不等于已成功访问 |
| 实际已读范围 | 摘要，或具体节、页、图、表、附录及必要上下文 | 未读部分没有某内容；局部阅读等于全文审读 |
| 支持某个主张 | 主张文本、原文定位、自写解释、适用条件、反证或限制 | 对所有项目/模型都成立；书目真实即可支持任意主张 |

核实引用版本和出版状态，区分预印本首发年、修订日期及正式发表年；arXiv DOI 不冒充会议或期刊 DOI。学校格式所需信息缺失时标待核实，不补造卷期页码。使用二手转述时显式记录二手关系，优先追溯原始出处；无法追溯就缩小可用结论。

没有联网工具时先检查本地已有文献、书目与阅读记录。有原文可做局部阅读并标记未在线核验；只有题名或摘要则限定在该范围。需要用户提供原文、访问方式或书目信息时说明具体缺项，并继续处理已能核实的部分。不要虚构检索结果，也不要为了形成完整参考文献表而填入未经核实的条目。

## 阅读到足以支持这句话

对每个拟引用的主张，执行“主张 → 原文 → 条件 → 可写范围”的核对。方法主张读方法及必要前提；结果主张读实验设置、指标定义、相应表图及解释；局限或因果主张核对其依据与作者限定。摘要可用于筛选和概述，不能代替这些核对。

阅读矩阵可使用下列最小字段，按复杂度增减，不追求空表数量：

```text
文献 ID；已核实书目/版本/原始链接；全文访问状态；实际阅读范围与日期
本节问题；研究对象/数据/条件；方法；指标与判分规则；主要结论及限制
主张 ID/拟用句；原文节页或图表定位；支持/部分支持/不支持/待核实
适用边界；相反或不同发现；关联正文位置；后续阅读
```

页码使用所读版本的页码，注明印刷页码或 PDF 页序；HTML 可用节名加图表编号和稳定链接，避免依赖会变化的网页行号。只保存必要的短引文，优先写自己的理解，不复制整篇原文。原文使用词语相似不等于论证支持；写清由哪项观察、设计或结果支撑当前句子。

## 按问题综合，而非逐篇列摘要

把相关研究放到同一问题下，比较对象、方法、数据条件、指标定义与结论。解释它们在哪个范围内一致、在哪个条件下不同，以及差异可能来自什么。将“作者解释”“自己的推断”和“当前材料未能判定”分开；缺少可比条件时说明不能作直接优劣排名。

比较数值前核对任务、数据版本/划分、样本、模型版本、输入条件、判分规则、单位与统计口径。名称相同的 accuracy 可能判分不同；名称不同的指标也不能因为都写成百分数就相减。不同批次的结果分别呈现，未做对照实验时不归因为单一方法优劣。

相反结论先核查是否回答同一问题，再检查条件差异，仍有冲突就保留并解释，不挑选支持自己方案的部分。文献可为设计动机提供依据，但不能代替当前项目的实现证据或测试结果。研究空缺只表述为本轮检索或已读范围内尚未找到的内容；摘要未报告某项，不等于全文未做，更不等于整个领域不存在。

## 写入正文与复核

正文围绕主题形成论证：研究问题、已有方法及其条件、共识/差异、与本研究的连接。具体检索过程、阅读状态和核验待办留在 Evidence；会改变读者判断的限制保留在相关结论附近。避免每句都加“仅供参考”等机械防御，也不删除真实的不确定性。

写完逐句核对关键引文：编号有对应书目，书目指向实际阅读版本，原文定位能支持这句话，限定条件没有被润色删掉。发现不支持的引用就删去或收窄主张，或补读正确来源；不要靠添加更多引用掩盖支持缺口。正文、书目或版本变化后，只复核受影响的主张及相邻比较。

交付时说明检索范围、实际阅读范围、仍缺材料和审查限制。产物齐全只能证明过程可追溯，不能自动证明文献综述完整、专业方法正确或论文质量提升。
