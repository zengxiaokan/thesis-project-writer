# 0.3.0 图表能力验证

日期：2026-10-29。此次验证包含图表指南接入、工作区保护、实际图表示例和三个独立行为场景。

## 脚本与实际导出

在本机 Windows Python 3.14.6 和独立的 Python 3.8.10 嵌入式运行时分别执行 31 项回归检查，均为 30 项通过、1 项目录符号链接用例因系统权限跳过。新增检查核对已有图源、数据、导出和图表索引的字节及修改时间保留，公开 CSV 与真实观察一致，非法计数不会被直接绘图。技能结构、文档链接、发行包内容及确定性检查通过。

[图表示例](../examples/figures/README.md) 的技术流程图由已有 DOT 引擎渲染 SVG，统计图由已有 Matplotlib 从[实际观察](../examples/initialization-study/observation.json)读取 4、2、15 三个计数后导出 SVG；CSV 逐项对应观察键。两个导出均转换为本地 PNG 进行目视检查，核对了中文、节点、箭头、分支、单位、零起点、数值及裁切；中文越框问题已修正。保留 DOT、数据、生成脚本及 SVG，同环境复跑的统计 SVG 和 CSV 字节一致。

CI 检查标准库回归、发行包及观察复跑，不要求每个运行器安装图表渲染依赖，也不把 CI 通过当作全部图种的视觉检查。跨平台状态以 [CI 对应提交](https://github.com/zengxiaokan/thesis-project-writer/actions)为准。

## 独立行为场景

使用修订技能和给定原始材料，由独立代理实际完成当前可交付部分，再人工核对。以下对应 [evals](../evals/evals.json) 的第 9—11 项，是定性检查，没有冒充真实作者反馈或自动质量评分。

| 场景 | 实际行为 | 本轮判断 |
| --- | --- | --- |
| 报名流程及物理 ER，SQL 无外键 | 给出完整 Mermaid 流程源与两表 DOT 源，保留活动不存在/未开放和组合唯一约束拒绝路径；未补 student 表或物理外键，并提供题注与配套正文 | 关系依据、组合约束及文本源交付边界正确 |
| 单批次 12 项测试结果 | 给出 10 通过、1 失败、1 阻塞的文本分布、可编辑表格及 CSV；分母未知时不计算通过率，未生成性能曲线或伪称已导出 | 数据与口径保持，没有美化成全通过 |
| 只改已有图4-2，缺渲染和 Word 写回 | 直接交完整修订 Mermaid，将判断改为活动开放且有名额；沿用图号与拒绝出口，给具体题注及正文同步文字，保留未渲染/未写回项 | 局部任务直接接续，没有重开访谈或假称页面完成 |

共十一项场景定义不代表本轮全部实跑。实际示例覆盖一张初始化器流程图和一张计数图，尚未验收真实论文的全部图表、各图种在所有工具中的渲染或学校 Word 页面。
