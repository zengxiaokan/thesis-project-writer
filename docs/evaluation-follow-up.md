# 评估报告改进跟踪

依据作者提供的 2026-10-28《thesis-project-writer 可行性与质量评估》核对后进行本轮改进。报告中的主观评分、其他宿主兼容性描述和测试声明均不直接作为本仓库验证结论；原 HTML 不随仓库分发。

| 评估事项 | 本轮处理 | 验证与尚未覆盖的范围 |
| --- | --- | --- |
| 没有开源许可 | 作者明确选择 MIT，加入 LICENSE、技能许可字段与发行包 | 许可文本依据 [OSI 的 MIT 文本](https://opensource.org/license/mit)；不把用户论文、数据或外部材料纳入仓库许可 |
| 没有完整论文端到端记录 | 增加基于真实初始化器的单节流程样例及原始观察 | 可以复跑程序观察；样例只覆盖一个小节，不宣称完成真实毕业论文或证明跨题目稳定性 |
| Codex 绑定 | 保留专用元数据，增加其他宿主手动加载指南 | 未验证某宿主自动识别 SKILL.md、自动读取 AGENTS.md 或具备指定工具，不沿用报告中未经核实的具体安装承诺 |
| ZIP 缺说明、许可且有行尾差异 | 加入 README、LICENSE、VERSION、CHANGELOG、适配指南与样例，补确定性构建及检查工具 | 以明确发行清单为准；LF/CRLF 检出生成相同字节；不将 CI、缓存、本机审查资料或 ZIP 自身装入发行包 |
| Python 3.8 未实测 | 配置 Linux/Windows 的 3.8/3.12/3.14 CI | 对应提交的运行记录才是通过依据；配置存在不代表执行已通过，AST 也不代替实际解释器 |
| 没版本记录与 CI | 加入首个版本号 0.1.0、更新记录及自动检查 | 未捏造此前发布版本或用户反馈；是否发布 GitHub Release 与源码版本分别处理 |
| TOCTOU 窗口 | 保留全量预检，并在每次 mkdir/open 前重新检查目标与祖先目录 | 增加可控目录替换用例，但检查仍非原子，不保证抵御持续并发攻击或自动回滚 |
| 终端编码依赖（复核补充） | CLI 用 ASCII 转义 JSON 输出 | 增加 ASCII 终端下中文路径测试，解析值保持正确 |

验证分为初始化与发行脚本回归、真实程序观察、单节文字审查、宿主使用、完整论文质量五个不同范围。前几类成功不自动扩大成后两类验收。每次改动后只复核受影响的范围。
