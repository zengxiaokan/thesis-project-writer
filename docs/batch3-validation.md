# 第三批：文献综合与大材料接续验证

日期：2026-10-29；候选版本0.6.0。只更新独立技能仓库，未修改已安装技能或正式论文。

本轮增加通用文献工作流、真实文献小例、只读材料清单和接续指南，并实际执行一个新合成软件项目的两阶段任务及一次文献修订。原始输入、评分、模型产物和独立代理评审分别保留。本轮没有无技能/旧版对照，不报告相对质量、成本或稳定性增益。

## 连续任务怎样执行

材料是本轮新合成的社区订货项目；初始20个业务模块共30份文件、22,448字节。同名`service.py`分别位于完整模块路径下，另有配置连接的后台入口及跨模块调用。题目、评分、规则和变更计划在首轮前冻结，运行者不读取评分或变更计划。它是内部合成试点，不是来自外部组织的真实留出项目。

首轮新代理分析全部材料并撰写4.3“订单创建与取消”，生成画像、正文、Mermaid图源、测试计划、主张和checkpoint。随后仅在另一个材料副本改变取消允许状态，修改入口注册/修订，并新增召回模块：两个已有源码路径修改、一个新增，共三个源码路径变化。V1输入保留原样，V2为21模块、31份文件、23,210字节。

接续代理不继承首轮对话，只拿到V2、候选规则及首轮成果；先比较清单与基线再继续六份产物。两轮均禁止执行业务、联网或读取其他评测。通过外部读取器记录向代理返回的源码路径与指纹，规则和已生成产物可直接读取。该约定不是操作系统隔离，也不能证明代理实际理解了每段返回内容。

独立代理回查源材料与产物，另审模块规则、入口连接、机制解释、图文/计划同步与主张基线，不以作者自报覆盖数作结论。它是代理评审，未冒充人类或匿名比较。

首轮评审确认20个模块、6条关键链均满足，未发现关键事实错误或实质漏项。有1项低风险问题：主张记录中指向`analysis.md`的定位统一采用宽泛模板，人工可沿正文/蓝图找到事实，但跳转和接续定位精度较弱；例如`C-CONTEXT-001`的蓝图位置与事实说明位置并不相同。原始产物与具体位置保留在评审中，没有事后修饰成全项完美。

接续的关键语义与同步经回查成立：发现新增召回入口和21个模块，正文/图源/计划同步允许`packing`取消、召回整单和外层快照回滚；后台维护仍只选`reserved`，没有补造拣货/包裹清理或外部资金移动。31份来源指纹登记相符，26条未变主张和6段未受影响正文原文保留。未发现关键事实错误。

接续的7项要求与21模块内容均满足，也继承了上述28条宽泛`analysis.md`定位（LOC-01）。读取计量判为部分完成：旧缓存显示和旧产物事件缺少统一自动记录（READ-01，中）；部分`analysis`/checkpoint“本轮阅读路径”“重复0”字段仅指读取器，没有在字段名上完整涵盖缓存（READ-02，低），须结合补充范围解读。原件保留，未将其包装为完整隔离或效率验证。

## 读取观察的解释

| 活动 | 首轮 | 新代理接续 |
| --- | ---: | ---: |
| 模型通过读取器取得当前项目内容的不同源文件 | 30 | 3 |
| 模型另从首轮缓存显示的源文件（代理补充记录） | 0 | 8 |
| 清单指纹扫描读取的文件 | 30 | 31 |
| 指纹扫描读取的原始字节 | 22,448 | 23,210 |

接续通过读取器取得`orders`、`registry`、`recalls`三个当前源码；另从旧缓存向模型显示`store`及`catalog`、`inventory`、`refunds`、`picking`、`packing`、`shipping`、`recovery`八份原文，用于复核直接连接和未变边界。因此不能把3份表述为全部模型源码阅读。八份缓存原文的显示范围由代理补充记录，未由读取器自动计量。

清单哈希确实读取了全部选定源文件。接续的Python解析还加载了五份首轮打包缓存中的全部旧文本；不是工具层只读取八份缓存。上表不包含规则、checkpoint与其他旧产物阅读，不能换算为总I/O、token、耗时或理解质量的下降。接续是否正确另由语义评审决定。下次评测应仅交正式接续产物并通过统一读取器取得所需原文，避免缓存包造成计量缺口。

两轮源文件的字节、修改时间和路径集合在各自运行前后对比；存档保留快照及结果，访问时间不作保证。开发审查曾复现“外部日志为项目源文件硬链接时追加会修改源文件”的缺口，已拒绝多链接日志和链接/重解析日志，并补只读回归。实际评测日志是新建的普通单链接文件，事件格式与统计含义未改变；不承诺并发替换下的原子隔离。

## 文献前向检查

使用与公开小例相同的三篇论文，只向新代理提供版本化官方URL、指南和待修段落，不交阅读矩阵或评分。单次运行产出修订正文、实际访问日志和主张支持记录。独立代理再打开三篇官方原文关键位置，五项各2分，共10/10，未发现实质错误：纠正了无条件正确性保证、跨口径排名以及由摘要推全文和领域空白的论断，并形成可继续使用的段落。

该题属于已知来源前向检查，不能当作外部留出、全面检索、效果对照或重复实验。原运行记录24次操作，不等于24篇文献或24次成功访问；独立评审核对了关键支持及记录自洽性，未证明原工具日志完整性或全部自报阅读行为。原运行记录PDF截图未成功呈现，核查基于实际取得的文本；独立评审没有把该自述当成已复现的图像检查。
