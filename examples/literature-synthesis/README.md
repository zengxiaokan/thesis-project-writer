# 小型文献综合实例

日期：2026-10-29。本例示范如何保留书目、阅读范围与主张支持的区别，使用三篇真实计算机论文的官方原始页面进行定向核验。它是可复查的读书产物，不是某篇毕业论文的现成相关工作，也不是全面领域检索、系统综述或专业方法验收。

按以下顺序复查：

1. [检索日志](search-log.json)：这些条目来自预先选定的标识符查找；没有实际执行广泛关键词检索。
2. [阅读矩阵](reading-matrix.json)：核对版本、所读位置、未读范围与逐条主张。
3. [主题综合](synthesis.md)：检验比较是否围绕同一问题，以及哪些比较需要停止。
4. [审查记录](review.md)：检查错误归因、指标误比和摘要范围被放大的三个陷阱。

前两篇只进行有目的的局部阅读；第三篇仅阅读摘要页，未打开全文。网页工具附带显示的相邻内容不算已精读。目录不存整篇论文、摘录长段或实验复现数据；原始链接和节名用于回到来源核验。

如将本例用于评测，先让运行者基于原始材料产出自己的记录，再单独评分。此处的矩阵和审查是示例答案性质的读书记录，不能同时作为隐藏评分材料，又让被评测代理预先读取。
