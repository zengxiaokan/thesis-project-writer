# 文献流程前向小测

本题与 `examples/literature-synthesis/` 使用同组三篇已知文献，检查候选流程能否在一次新的修订任务中产生可复查产物。它不是外部留出题、盲测、对照增益实验或领域覆盖评测。若运行者此前接触过本题或公开示例，需在运行记录中说明，不据此声称独立发现能力。

运行输入与评分分开：运行者只接收 [input.md](input.md) 及本轮拟使用的技能参考流程，不读取本目录其他文件或公开示例答案。输入只有三条版本化官方 arXiv 链接和待修段落，没有 `reading-matrix.json` 答案。访问原文应遵守实际工具能力并记录读取范围。

[grading.json](grading.json) 仅由评分者在原始输出保存后读取，用于逐项评分。不要把评分条件、答案定位或公开示例矩阵注入运行提示。若交由代理运行，明确指定可读输入路径；文件同在仓库并不自动构成读取授权。

保留修订正文、核验记录、实际来源访问记录和评分理由。没有访问记录时不得推断模型确已打开或阅读全文。本题目前只提供题目与独立评分条件；本目录自身不代表已经运行或通过。结果报告应说明哪些错误被修复、哪些依据不足，不能只凭总分声称论文质量提高。
